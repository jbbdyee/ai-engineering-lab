## 4. 한 가지씩 바꾸고 재기 (Lab 03)

| 설정 | 청크 수 | doc@1 | answer@1 | answer@3 |
| --- | --- | --- | --- | --- |
| 섹션 (기준) | 25 (문서의 `##` 개수) | /24 | /24 | /24 |
| 200자 |  | /24 | /24 | /24 |
| 400자 |  | /24 | /24 | /24 |
| (내가 바꾼 것) |  | /24 | /24 | /24 |

- 위 검색 점수는 아직 측정하지 않았다. `my-index`를 해당 설정으로 실행한 뒤 `retrieval-*` 세 테스트를 `--no-before`로 실행하고 결과를 적는다.
- 수업 자료에 적힌 과거 기준 측정값은 섹션 25개, doc@1 24/24, answer@1 22/24, answer@3 24/24이다. 이는 현재 실행 결과가 아니다.
