## 1. v1 → v2에서 바뀐 것 (Lab 01 예제 1 · `flow.py diff`)

| 바뀐 곳 | 전 | 후 | 답에 생길 영향 (내 짐작) | 실제로 (`call rel-v1` · `rel-v2`) |
| --- | --- | --- | --- | --- |
| 지시문 | FAQ 출처 번호 지시 없음 | `Answer.systemMessage`에 FAQ 답 끝에 `[FAQ-003]`처럼 id를 붙이고 짧게 쓰라는 문장 추가 (307 → 419자) | FAQ 답에 출처 번호가 붙고 짧아질 수 있음 | v1 답에는 번호 없음. v2 답 끝에 `[FAQ-003]` 표시. 어느 변경이 답의 길이를 바꿨는지는 이 비교만으로 알 수 없음. |
| 모델 | `gpt-4.1-mini` | `gpt-5.4-nano` | 표현·길이·응답 시간이 달라질 수 있음 | 같은 VPN 질문에 v1 2.8초, v2 1.1초. 한 번씩 잰 값이라 모델의 속도 차이로 단정할 수 없음. |
| 노드 · 연결 | `Answer → Build result` 직접 연결; 웹훅 `rel-v1` | `Review check` Code 노드 추가; `Answer → Review check → Build result`로 연결 변경; 웹훅 `rel-v2` | 새 노드는 답을 최대 400자로 자름. 웹훅 경로는 요청 주소만 바꿈. | 두 호출 모두 HTTP 200, `route`는 `자동 답변`, `sources`는 `["FAQ-003"]`. 이번 답은 400자 미만이라 자르기 영향은 관찰되지 않음. |

`flow.py diff`의 변경 7개: 노드 추가 1개, 지시문 변경 1개, 모델 변경 1개, 웹훅 경로 변경 1개, 연결 추가 2개, 연결 제거 1개. v1 답은 VPN 클라이언트 업데이트와 인증서 만료 확인, 관련 문의 및 담당 직원 안내를 포함했다. v2 답은 업데이트와 인증서 만료 확인 뒤 `[FAQ-003]`으로 끝났다. 지시문·모델·흐름이 동시에 바뀌었으므로 답의 개별 변화 원인은 분리해서 확인해야 한다.
