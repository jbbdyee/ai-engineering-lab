# AI Engineering Lab

AI Agent, 워크플로 자동화, DevOps를 배우며 수업 자료와 개인 실습을 함께 정리하는 저장소입니다. 수업 자료의 원본은 [선생님 GitLab](https://gl.isitsoft.kr/publicproj/aio-01d4-stu)이며, 이 저장소에는 학습 과정에서 작성·수정한 내용도 포함됩니다.

## 살펴보기

- [`Lecture/`](Lecture/) — 수업별 개념 설명과 진행 자료
- [`Last3Mon/`](Last3Mon/) — 날짜별 실습, 예제 워크플로, `miniflow`와 n8n 자료
- [`Doc/`](Doc/) — 과정 일정 자료

현재 공개된 실습은 64~66일차의 워크플로 설계, LLM·도구·메모리 연결, 조건 분기, n8n, 데이터 파싱과 반복·병렬 처리 등을 다룹니다. 각 실습의 실행 방법은 해당 날짜의 README와 안내 문서를 참고해 주세요.

이 저장소는 수업 진행에 따라 갱신됩니다. 선생님 자료와 개인 실습이 같은 폴더에 있을 수 있으므로, 변경 이력을 확인하면 학습 과정에서 추가한 내용을 구분할 수 있습니다.
